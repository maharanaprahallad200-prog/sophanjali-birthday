SOPHANJALI'S BIRTHDAY SURPRISE WEBSITE 💖
Birthday: November 1
Made with love by Prahallad.

OPEN LOCALLY
1. Extract this ZIP file.
2. Open the extracted folder in VS Code (File > Open Folder).
3. Double-click index.html in File Explorer to open it in a browser, or use Live Server.
4. Click “Someone has a surprise for you…” to enter the website.
5. The official YouTube song “sun saawariya” starts when you click “Someone has a surprise for you…”. Use the bottom-right button to stop or restart it.

NOTE ABOUT MUSIC
The website embeds the official YouTube video for “sun saawariya” by Accha Insaan, AtharvaMusic and Yaani Karnawat. Browsers usually block audible autoplay until the visitor clicks, so the song starts when the visitor taps the opening surprise button. An internet connection is required.

ADD PHOTOS LATER
1. Create a folder named images inside this website folder.
2. Copy photos into it, for example sophanjali1.jpg and sophanjali2.jpg.
3. In index.html, find the photo-grid section and replace each photo-placeholder with:
   <div class="photo-card">
     <img src="images/sophanjali1.jpg" alt="Sophanjali smiling">
     <p>My favourite smile 🌸</p>
   </div>
4. Add this to the bottom of style.css:
   .photo-card { background:white; padding:12px; border-radius:16px; box-shadow:0 12px 30px #b04d7118; }
   .photo-card img { width:100%; height:300px; object-fit:cover; border-radius:10px; display:block; }
   .photo-card p { font-family:'Playfair Display',serif; color:#c44570; }
Only use photos you have permission to share.


PHOTO GALLERY
All four photos are included in the images folder. Keep the images folder in the same folder as index.html. Open index.html to view the website.
